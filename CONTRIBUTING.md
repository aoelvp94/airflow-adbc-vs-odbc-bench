# Contributing

This is a personal demonstration repository by @aoelvp94 to show the value of ADBC in Apache Airflow.

## For Apache Airflow Improvements

This repository demonstrates existing Airflow functionality. For improvements to Airflow itself:

- **Main repository**: https://github.com/apache/airflow
- **Contributing guide**: https://github.com/apache/airflow/blob/main/CONTRIBUTING.rst
- **Slack**: https://apache-airflow.slack.com

## Feedback on This Demo

If you have feedback on this benchmark demonstration:

1. Open an issue in this repository
2. Describe what you'd like to see improved or added
3. Include your use case if relevant

## Running Your Own Benchmarks

Feel free to fork this repository and adapt it to your needs:

- Test different database systems (MSSQL, MySQL, etc.)
- Modify row counts and batch sizes
- Add more complex transformations
- Compare with other data processing patterns
